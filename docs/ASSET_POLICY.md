# 数据、模型与许可证边界

本仓库默认不分发模型权重、原始数据、处理后数据和实验日志。公开 GitHub 仓库只包含代码、测试、配置和复现实验协议。

## 第三方资产

以下资产来自第三方，使用或重新发布前必须以对应上游页面的最新条款为准：

- Qwen3.5-9B Base：模型权重、模型卡和使用条款以 Qwen 官方仓库为准。
- CMB：数据集内容、许可证和研究/商业使用限制以 FreedomIntelligence/CMB 数据卡为准。
- CMExam：数据来源、镜像版本和许可证以其上游数据集仓库为准。
- GSM8K：数据集条款以 openai/gsm8k 上游仓库为准。

本项目不把上述数据或权重重新授权给使用者，也不保证第三方资产适用于生产医疗服务。

## 发布前检查

发布 release 或上传服务器前，应为每项外部资产记录：

1. 来源 URL 和固定 revision/commit；
2. 下载时间、文件大小和 SHA256；
3. 上游许可证或使用条款链接；
4. 本项目的处理方式、过滤规则和输出文件 hash；
5. 是否允许随 release 或服务器镜像一起分发。
